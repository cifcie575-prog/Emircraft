# Emircraft

Emircraft, Minecraft'tan ilham alan, Android için geliştirilen blok tabanlı bir sandbox oyunudur.

## Özellikler

- 🌍 Açık dünya
- 🧱 Blok yerleştirme
- ⛏️ Blok kırma
- 🎒 Envanter sistemi
- 📱 Android desteği

## Geliştirme Durumu
